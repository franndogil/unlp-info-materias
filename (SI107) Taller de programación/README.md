# Taller de Programación

Materia estructurada en tres módulos: programación **imperativa** (Pascal), **orientada a objetos** (Java) y **concurrente** (Java). Cada módulo cuenta con su teoría, sus prácticas y su instancia de evaluación.

## Contenido

La carpeta está organizada por tipo de material (teoría, prácticas y finales), y dentro de cada uno por módulo (IMPERATIVO, OBJETOS, CONCURRENTE). Incluye enunciados, resoluciones propias, modelos de parcial y finales de distintas fechas.

Filminas y apuntes de cada módulo.

## Observaciones

- El código imperativo está en Pascal (`.pas`, con binarios `.exe`/`.o` acompañando algunas soluciones) y el de objetos/concurrente en Java (`.java`).
- Dentro de OBJETOS hay proyectos completos de NetBeans; los artefactos de compilación (`build/`, `nbproject/`) se ignoran vía `.gitignore`.
- La carpeta [Promocion](Promocion) contiene numeradas (`Foto (1)` … `Foto (52)`) fotografías de apuntes de clase.
