# Ingeniería de Software 1

Materia dedicada a la ingeniería de requerimientos y al modelado de sistemas. Aborda historias de usuario (HU), casos de uso (CU), diagramas de transición de estados (DTE), redes de Petri (RP), tablas de decisión (TD), modelos de proceso y metodologías ágiles.

## Contenido

La carpeta está organizada en teoría, prácticas, parciales y modelos de examen. Las prácticas incluyen enunciados, resoluciones y las plantillas de HU y CU.
